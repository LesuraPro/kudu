# Familiar Lite

Бесплатная самописная замена [Familiar Desktop](https://familiardesktop.com) ($10): оболочка поверх Windows в стиле Nothing — чёрное стекло, точечные (dot-matrix) цифры, красный акцент.

## Что внутри

| Часть | Что делает |
|---|---|
| **Остров** (сверху по центру) | Пилюля с часами из точек. Когда играет музыка, в ней бежит название трека и прыгает эквалайзер. При наведении раскрывается в плеер: обложка, ⏮ ⏯ ⏭, прогресс, дата, напоминания. Вкладка «Устройства» показывает батарею. |
| **Док** (снизу) | Закреплённые приложения, иконки увеличиваются под курсором. Можно перетаскивать, ПКМ открывает меню. |
| **Поиск** (Alt+Space) | Приложения из «Пуска» и файлы с рабочего стола и из «Документов». |
| **Визуализатор** | Круг из точек, реагирует на звук системы. Режимы PULSE, RIPPLE, TORUS, CLOCK, TICKER. |
| **Кассета** | Бобины крутятся, пока играет музыка, плёнка перематывается по ходу трека. Клик ставит на паузу. |
| **familiar-tty** | Терминал со сценами: 1 fetch (как neofetch), 2 cave, 3 life (игра «Жизнь»), 4 orb, 5 rain («Матрица»). |
| **Часы, погода, напоминания** | Погода берётся с Open-Meteo, без ключа. |

Каждый виджет — отдельное окно: его можно таскать мышкой, место запоминается. Визуализатор и терминал можно растягивать.

### Откуда берётся музыка

На Windows `media.ps1` читает системные медиаконтролы: те же, что всплывают у регулятора громкости. Поэтому работает со Spotify, Яндекс Музыкой, YouTube в браузере и т. д., без API-ключей.

Визуализатор слушает звук системы через loopback-захват Chromium (только Windows). Если захват не удался, справа внизу горит `SIM`: точки двигаются в такт по имитации, а не по реальному звуку. При живом звуке там `LIVE AUDIO`.

## Запуск (Windows)

Нужен [Node.js](https://nodejs.org) 20+.

```
cd familiar-lite
npm install
npm start
```

Демо без музыки, с выдуманным треком: `set FAMILIAR_DEMO=1 && npm start` (в PowerShell: `$env:FAMILIAR_DEMO=1; npm start`).

Собрать один .exe, который запускается без установки:

```
npm run package:win
```

Готовый файл появится в `dist/`. Для автозапуска положи ярлык на него в `shell:startup` (Win+R → `shell:startup`).

## Управление

- **Alt+Space** — поиск. Enter открывает, Ctrl+Enter закрепляет в доке.
- **Alt+W** — показать или скрыть все виджеты.
- **ПКМ по доку или виджету** — меню: какие виджеты показывать, раскладка по умолчанию, остров вкл/выкл, тема, настройки, выход.
- **Клавиши 1–5** в терминале переключают сцены.
- Перетащи ярлык или .exe из Проводника на док, чтобы закрепить.

## Настройки

`%APPDATA%\familiar-lite\config.json`: закреплённые приложения, город и координаты для погоды, тема, напоминания, положение виджетов.

## Устройство

- `main.js` — главный процесс: окна, горячие клавиши, поиск ярлыков, запуск, погода, музыка.
- `media.ps1` — мост к системному плееру Windows (PowerShell + WinRT).
- `preload.js` — какие функции главного процесса доступны окнам.
- `src/dotmatrix.js` — точечный шрифт 5×7 (латиница, кириллица, цифры).
- `src/media.js`, `src/audio.js` — состояние плеера и спектр звука для окон.
- `src/island.*`, `src/dock.*`, `src/launcher.*` — остров, док, поиск.
- `src/widget.html` + `src/widgets/*.js` — по файлу на виджет.
