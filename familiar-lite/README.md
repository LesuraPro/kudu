# Familiar Lite

Бесплатная самописная замена [Familiar Desktop](https://familiardesktop.com) ($10): mac-подобная оболочка поверх Windows.

| Функция | Familiar ($10) | Familiar Lite |
|---|---|---|
| Док с закреплёнными приложениями | ✅ | ✅ увеличение иконок под курсором, перетаскивание, ПКМ → открепить |
| Поиск по Alt+Space | ✅ | ✅ приложения из «Пуска» + файлы с рабочего стола и из «Документов» |
| Виджеты: часы, погода, напоминания, батарея | ✅ | ✅ погода через Open-Meteo (без ключа) |
| Светлая / тёмная тема | ✅ | ✅ |
| Запущенные приложения в доке | ✅ | ❌ нужен нативный код (WinAPI) |
| Виджет музыки | ✅ | ❌ |
| Обои | ✅ | ❌ используй [Lively Wallpaper](https://github.com/rocksdanister/lively) — бесплатно |

## Запуск (Windows)

Нужен [Node.js](https://nodejs.org) 20+.

```
cd familiar-lite
npm install
npm start
```

Собрать один .exe, который запускается без установки:

```
npm run package:win
```

Готовый файл появится в `dist/`. Чтобы оболочка запускалась вместе с Windows, положи ярлык на этот .exe в `shell:startup` (Win+R → `shell:startup`).

## Управление

- **Alt+Space** — поиск. Enter открывает, Ctrl+Enter закрепляет в доке.
- **Alt+W** — показать или скрыть виджеты.
- **ПКМ по доку** — открепить, сменить тему, открыть настройки, выйти.
- Перетащи ярлык или .exe из Проводника на док, чтобы закрепить.

Если Alt+Space уже занят (например, PowerToys Run), поиск открывается кнопкой ⌕ в доке.

## Настройки

`%APPDATA%\familiar-lite\config.json`: закреплённые приложения, город и координаты для погоды, тема, напоминания.

## Устройство

- `main.js` — главный процесс: окна, горячие клавиши, поиск ярлыков в меню «Пуск», запуск приложений, погода.
- `preload.js` — мост: какие функции главного процесса доступны окнам.
- `src/dock.*`, `src/launcher.*`, `src/widgets.*` — три окна на обычном HTML, CSS и JS.
