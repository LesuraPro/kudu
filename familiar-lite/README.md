# Familiar Lite

Бесплатная самописная замена [Familiar Desktop](https://familiardesktop.com) ($10): оболочка поверх Windows в стиле Nothing — чёрное стекло, точечные (dot-matrix) цифры, красный акцент. Код Familiar закрытый, поэтому всё написано с нуля по описанию с их сайта и скриншотам роликов.

## Что внутри

| Часть | Что делает |
|---|---|
| **Верхняя панель** | Как в macOS: ● FAMILIAR, имя активного приложения, меню (виджеты, обои, профиль, тема), справа — что играет, мини-график ЦП, память, батарея, дата и время. На Windows резервирует полосу экрана, чтобы развёрнутые окна не заезжали под неё. |
| **Остров** (в центре панели) | Пилюля с часами из точек. Когда играет музыка, в ней бежит название трека и прыгает эквалайзер. При наведении раскрывается в плеер: обложка, ⏮ ⏯ ⏭, прогресс, дата, напоминания. На вкладке «Устройства» — заряд ноутбука и Bluetooth-устройств (наушники, мышки). Кнопка ☾ переключает тему. |
| **Док** (снизу) | Закреплённые приложения и запущенные, как в macOS. Точка под запущенным, красная чёрточка под активным. Клик по запущенному переключает на него, повторный клик сворачивает. Иконки увеличиваются под курсором. |
| **Поиск** (Alt+Space) | Приложения из «Пуска», игры из Steam и Epic, файлы с рабочего стола и из «Документов». |
| **Визуализатор** | Круг из точек, реагирует на звук системы. Режимы SPACE, PULSE, RIPPLE, TORUS, CLOCK, TICKER. Если сжать окно, остаётся только «глаз». |
| **Глазки** | Пиксельные глаза: следят за курсором, моргают, радуются музыке, засыпают, если долго не трогать мышь, удивляются, если навести на них курсор. |
| **Кассета** | Бобины крутятся, пока играет музыка, плёнка перематывается по ходу трека. Клик ставит на паузу. |
| **Нагрузка** | График ЦП или памяти за 2 минуты и процент точками. |
| **Игры** | Обложки установленных игр из Steam и Epic, клик запускает игру. |
| **familiar-tty** | Терминал со сценами: 1 fetch (как neofetch), 2 cave, 3 life (игра «Жизнь»), 4 orb, 5 rain («Матрица»). |
| **Часы, погода, напоминания** | Погода берётся с Open-Meteo, без ключа. |
| **Свои виджеты** | Любой .js в папке виджетов становится виджетом. Для примера там лежит таймер Помодоро. |
| **Обои** | Четыре варианта (красная планета, точечная сетка, горизонт, светлая бумага), рисуются под разрешение экрана. |
| **Профили** | «Основной», «Учёба», «Игры»: у каждого свои закреплённые приложения и набор виджетов с расположением. |

Каждый виджет — отдельное окно: его можно таскать мышкой, место запоминается. Визуализатор, глазки, нагрузку, игры и терминал можно растягивать.

### Откуда что берётся

- **Музыка, окна, фокус, панель, обои** — `bridge.ps1` (PowerShell + WinRT + WinAPI). Он запускается в фоне и работает со всем, что видно в регуляторе громкости Windows: Spotify, Яндекс Музыка, YouTube в браузере. API-ключи не нужны.
- **Звук для визуализатора** — loopback-захват Chromium (только Windows). Если захват не удался, справа внизу горит `SIM`: точки двигаются в такт по имитации. При живом звуке там `LIVE AUDIO`.
- **Заряд Bluetooth-устройств** — то же значение, что в «Параметры → Bluetooth». Если там у устройства нет процента, у нас его тоже не будет.
- **Игры** — файлы библиотек Steam (`libraryfolders.vdf`, `appmanifest_*.acf`) и манифесты Epic Games Launcher.

## Запуск (Windows)

Нужен [Node.js](https://nodejs.org) 20+.

```
cd familiar-lite
npm install
npm start
```

Демо без Windows и музыки, с выдуманными треком, окнами, играми и наушниками: `$env:FAMILIAR_DEMO=1; npm start` (в cmd: `set FAMILIAR_DEMO=1 && npm start`).

Собрать один .exe, который запускается без установки:

```
npm run package:win
```

Готовый файл появится в `dist/`. Для автозапуска положи ярлык на него в `shell:startup` (Win+R → `shell:startup`).

## Управление

- **Alt+Space** — поиск. Enter открывает, Ctrl+Enter закрепляет в доке.
- **Alt+W** — показать или скрыть все виджеты (или клик по часам в панели).
- **ПКМ по доку или виджету** — общее меню: виджеты, обои, профиль, тема, остров и панель вкл/выкл, выход.
- **ПКМ по запущенному приложению в доке** — закрепить его.
- **Клавиши 1–5** в терминале переключают сцены.
- Перетащи ярлык или .exe из Проводника на док, чтобы закрепить.

## Свои виджеты

1. ПКМ по доку → Виджеты → «Папка своих виджетов…» (это `%APPDATA%\familiar-lite\widgets\`).
2. Положи туда `мой-виджет.js`. Внутри вызови `Widget.define('мой-виджет', (card) => { ... })`, имя должно совпадать с именем файла.
3. ПКМ → Виджеты → «Обновить свои виджеты».

Все доступные функции описаны в комментарии в начале `examples/pomodoro.js`. Свой виджет получает тот же доступ, что и встроенные (может запускать программы), поэтому не клади туда файлы из непроверенных источников.

## Настройки

`%APPDATA%\familiar-lite\config.json`: закреплённые приложения, город и координаты для погоды, тема, напоминания, положение виджетов, профили.

## Устройство

- `main.js` — главный процесс: окна, меню, док, профили, обои.
- `lib/bridge.js` + `bridge.ps1` — связь с Windows; в демо-режиме выдуманные данные.
- `lib/apps.js`, `lib/games.js`, `lib/system.js` — поиск приложений, игры, нагрузка и батареи.
- `preload.js` — какие функции главного процесса доступны окнам.
- `src/dotmatrix.js` — точечный шрифт 5×7 (латиница, кириллица, цифры).
- `src/media.js`, `src/audio.js` — состояние плеера и спектр звука для окон.
- `src/menubar.*`, `src/island.*`, `src/dock.*`, `src/launcher.*`, `src/wallpaper.*` — панель, остров, док, поиск, обои.
- `src/widget.html` + `src/widgets/*.js` — по файлу на виджет.
- `examples/pomodoro.js` — пример своего виджета, при первом запуске копируется в папку виджетов.
