# Familiar Lite

Бесплатная самописная замена [Familiar Desktop](https://familiardesktop.com) ($10): оболочка поверх Windows — стекло, точечные (dot-matrix) цифры, моноширинный текст. Код Familiar закрытый, поэтому всё написано с нуля по описанию с их сайта и скриншотам роликов.

Оформление по умолчанию — палитра **«Луна и клинок»**, снятая с обоев: чёрная тушь с синевой ночного неба вместо фона, лунный свет вместо белого, светящийся малиновый акцент, как клинки, и розовый, как лепестки. Прежний стиль Nothing (чёрное с красным) остался на выбор, а палитра **«Из обоев»** подбирает цвета под любые свои обои сама.

## Что внутри

| Часть | Что делает |
|---|---|
| **Верхняя панель** | Как в macOS: ● FAMILIAR, имя активного приложения, меню (виджеты, обои, профиль, тема), справа — что играет, мини-график ЦП, память, батарея, дата и время. На Windows резервирует полосу экрана, чтобы развёрнутые окна не заезжали под неё. |
| **Остров** (в центре панели) | Пилюля с часами из точек. Когда играет музыка, в ней бежит название трека и прыгает эквалайзер. При наведении раскрывается в плеер: обложка, ⏮ ⏯ ⏭, прогресс, дата, напоминания. На вкладке «Устройства» — заряд ноутбука и Bluetooth-устройств (наушники, мышки). Кнопка ☾ переключает тему. |
| **Док** (снизу) | Закреплённые приложения и запущенные, как в macOS. Точка под запущенным, красная чёрточка под активным. Клик по запущенному переключает на него, повторный клик сворачивает. Иконки увеличиваются под курсором. Закреплённая папка раскрывается «веером» с содержимым. |
| **Поиск** (Alt+Space) | Приложения из «Пуска», игры из Steam и Epic, всё из папки Familiar, файлы с рабочего стола и из «Документов». |
| **Папка Familiar и «Ярлыки»** | `%USERPROFILE%\Familiar` — твой «рабочий стол» внутри Familiar. Виджет «Ярлыки» показывает её значками. Перетащи на него файл или папку из Проводника — появится ярлык, оригинал останется на месте; «убрать ярлык» удаляет только ярлык. |
| **Файлы** | Свой проводник: места слева, путь, поиск, «назад/вперёд», значки или список. Открывает файлы и папки; перемещать и переименовывать — в Проводнике, как и в оригинале. |
| **Настройки** | Профиль (имя, фото, список профилей), тема, палитра и обои с превью, виджеты, панель и остров, город для погоды с поиском, конвертер, быстрые ссылки на «Параметры» Windows, клавиши. |
| **Визуализатор** | Круг из точек, реагирует на звук системы. Режимы SPACE, PULSE, RIPPLE, TORUS, CLOCK, TICKER. Если сжать окно, остаётся только «глаз». |
| **Глазки** | Пиксельные глаза: следят за курсором, моргают, радуются музыке, засыпают, если долго не трогать мышь, удивляются, если навести на них курсор. |
| **Кассета** | Бобины крутятся, пока играет музыка, плёнка перематывается по ходу трека. Клик ставит на паузу. |
| **Нагрузка** | График ЦП или памяти за 2 минуты и процент точками. |
| **Игры** | Обложки установленных игр из Steam и Epic, клик запускает игру. |
| **familiar-tty** | Терминал со сценами: 1 fetch (как neofetch), 2 cave, 3 life (игра «Жизнь»), 4 orb, 5 rain («Матрица»). |
| **Часы, погода, напоминания** | Погода берётся с Open-Meteo, без ключа; город выбирается в настройках. |
| **Календарь** | Месяц точечным шрифтом, сегодня — красным, у дней с напоминаниями — точка. Клик по дню — его напоминания и поле, чтобы добавить новое на эту дату. |
| **Свои виджеты** | Любой .js в папке виджетов становится виджетом. Для примера там лежит таймер Помодоро. |
| **Обои** | Пять своих вариантов рисуются под разрешение экрана: «Луна и клинок» (луна, взрыв туши, два светящихся клинка, лепестки), красная планета, точечная сетка, горизонт, светлая бумага. Или ставь любую свою картинку — WebP и GIF сами перекодируются в JPG, который Windows точно поставит. |
| **Палитры** | «Луна и клинок», «Nothing» и «Из обоев»: цвета подбираются по картинке — фон из тёмных мест, акцент — самый «сочный» цвет, непохожий на фон (маленький светящийся клинок важнее огромного синего неба). Работает для светлой и тёмной темы. |
| **Конвертер** | По мотивам [DragShift](https://github.com/llamaboi55/DragShift): тащишь файл, жмёшь Shift — под курсором круговое меню, бросаешь на сектор — рядом результат. 10 форматов картинок, PDF ↔ Word, пароль на PDF, окна обрезки, правки, пометок и т.д. Подробнее ниже. |
| **Расписание пар** | Сегодняшние пары: текущая подсвечена и показывает, сколько осталось, у следующей — через сколько начнётся. Числитель и знаменатель. После последней пары — расписание на завтра. Пары вводятся в «Настройки → Расписание» (есть кнопка «Вставить пример»). |
| **Заметки** | Текст сохраняется сам. Строка «- [ ] дело» — пункт списка, Ctrl+Enter отмечает его. |
| **Обратный отсчёт** | Сколько дней до сессии, экзамена или отпуска — большими точками. Щелчок по подписи — поменять событие. |
| **Таймер фокуса** | Помодоро прямо в острове: вкладка «Фокус» (25, 50 минут, перерыв) или «фокус 25» в поиске. Пока идёт — в пилюле обратный отсчёт; в конце — три сигнала и уведомление. |
| **Быстрые ответы в поиске** | Калькулятор («2+2*3», «20% от 1500», «sqrt(2)»), перевод единиц («10 км в мили», «36,6 c в f», «1 гб в мб»), команды («сон», «заблокировать», «выключить через 30», «корзина», «эко», «тема», «пауза»), поиск в Яндексе или Google («? запрос»). Enter на ответе копирует его. Опасные команды спрашивают подтверждение. |
| **Эко-режим** | Вдвое меньше кадров везде — в меню (ПКМ по доку), в «Панель и остров» или «эко» в поиске. Там же — «Запускать вместе с Windows». |
| **Музыка с клавиатуры** | Ctrl+Alt+Пробел — пауза/играть, Ctrl+Alt+← → — треки, из любой программы. |
| **Профили** | Сколько угодно профилей с именем и фото. У каждого свои закреплённые приложения, набор и расположение виджетов, тема, палитра и обои. Новый профиль начинается копией текущего. |

Каждый виджет — отдельное окно: его можно таскать мышкой, место запоминается. Визуализатор, глазки, нагрузку, игры, ярлыки и терминал можно растягивать.

### Чего нет по сравнению с оригиналом

- «Следующая песня» в музыке — Windows не сообщает, какой трек будет следующим.
- Подключение Google/Outlook-календаря — в бете оригинала его тоже пока нет.
- Фотообои (Фарерские острова и т.п.) — их нельзя просто взять и положить в открытый проект; ставь любую свою картинку через «Своя картинка…».

### Откуда что берётся

- **Музыка, окна, фокус, панель, обои** — `bridge.ps1` (PowerShell + WinRT + WinAPI). Он запускается в фоне и работает со всем, что видно в регуляторе громкости Windows: Spotify, Яндекс Музыка, YouTube в браузере. API-ключи не нужны.
- **Звук для визуализатора** — loopback-захват Chromium (только Windows). Если захват не удался, справа внизу горит `SIM`: точки двигаются в такт по имитации. При живом звуке там `LIVE AUDIO`.
- **Заряд Bluetooth-устройств** — то же значение, что в «Параметры → Bluetooth». Если там у устройства нет процента, у нас его тоже не будет.
- **Игры** — файлы библиотек Steam (`libraryfolders.vdf`, `appmanifest_*.acf`) и манифесты Epic Games Launcher.

## Запуск (Windows)

Нужен [Node.js](https://nodejs.org) 20+.

```
cd familiar-lite
npm install
npm start
```

Демо без Windows и музыки, с выдуманными треком, окнами, играми и наушниками: `$env:FAMILIAR_DEMO=1; npm start` (в cmd: `set FAMILIAR_DEMO=1 && npm start`).

Собрать один .exe, который запускается без установки:

```
npm run package:win
```

Готовый файл появится в `dist/`. Для автозапуска положи ярлык на него в `shell:startup` (Win+R → `shell:startup`).

## Управление

- **Alt+Space** — поиск. Enter открывает, Ctrl+Enter закрепляет в доке.
- **Alt+W** — показать или скрыть все виджеты (или клик по часам в панели).
- **Ctrl+Alt+Пробел**, **Ctrl+Alt+← →** — музыка: пауза и треки.
- **В поиске**: «2+2», «10 км в мили», «фокус 25», «сон», «? запрос» — см. «Быстрые ответы» выше.
- **Ctrl+Alt+Q** — выйти. Открытые программы Windows продолжат работать.
- **ПКМ по доку или виджету** — общее меню: виджеты, обои, профиль, тема, остров и панель вкл/выкл, выход.
- **ПКМ по запущенному приложению в доке** — закрепить его.
- **Клавиши 1–5** в терминале переключают сцены.
- Перетащи ярлык или .exe из Проводника на док, чтобы закрепить.

## Конвертер (по мотивам DragShift)

Идея, жест и набор действий — из [llamaboi55/DragShift](https://github.com/llamaboi55/DragShift) (MIT, Python + PySide6). Здесь всё переписано на JavaScript и встроено в оболочку: меню и окна в нашем стиле, тот же процесс, те же уведомления. Набор действий сверен с исходниками оригинала (`convert.py`, `app.py`, `tools.py`, `trigger.py`).

**Как пользоваться**

1. Начни тащить файл — откуда угодно: Проводник, рабочий стол, браузер, Telegram, «Файлы», «Ярлыки».
2. Нажми **Shift** — под курсором появится круговое меню. Ещё раз Shift (не отпуская файл) — переключение «Формат» ↔ «Правка».
3. Отпусти файл на секторе. Результат появится рядом (или в подпапке «Преобразовано»), оригинал не меняется. Наведи на сектор — в центре подсказка, что он делает.
4. В уведомлении: «Открыть», «В папке», «Отменить» (созданное уходит в корзину).

Без перетаскивания: ПКМ по файлу → «Отправить» → «Familiar — преобразовать», или «Преобразовать…» в контекстном меню «Файлов» и «Ярлыков».

| Файл | Формат | Правка |
|---|---|---|
| Картинки: JPG, PNG, WebP, GIF, BMP, AVIF, ICO | JPG, PNG, WebP, TIFF, BMP, PDF, ICO (16–256 px в одном файле), GIF; в свой же формат не предлагает; несколько картинок → один PDF | Окна: Сжать (по качеству или до размера, сравнение «было/стало»), Размер, Обрезать (пропорции, поворот), Правка (яркость, контраст, насыщенность, тепло, резкость, Ч/Б, «Авто», поворот, отражение), Пометки (стрелка, рамка, овал, карандаш, маркер, текст, шаги 1-2-3), Скрыть (чёрным, пикселями, размытием), Фон (градиент, поля, скругление, тень, формат), Метаданные |
| PDF | JPG или PNG (по странице), DOCX, TXT | Сжать, разделить, повернуть, склеить, пароль, достать картинки, метаданные |
| Word (.docx) | PDF (через Microsoft Word, если он есть, иначе встроенной отрисовкой), TXT | — |
| Текст: .txt, .md, .csv… | PDF (Markdown — с заголовками и списками), DOCX | — |

Особенности:

- **Метаданные убираются без пересжатия**: из JPEG, PNG и WebP вырезаются блоки EXIF/XMP/IPTC, сами пиксели остаются байт в байт. Окно «Метаданные» показывает камеру, дату, выдержку, диафрагму, ISO и координаты; кнопка «Убрать GPS» стирает **только геолокацию** прямо в EXIF (файл того же размера, камера и дата на месте). Снимок, повёрнутый через EXIF (так делают телефоны), при полной очистке перекодируется с учётом поворота — иначе он лёг бы набок.
- **Пароль на PDF** — AES-256 (PDF 2.0, как у оригинала), печать и копирование разрешены. Шифрование написано своё (`lib/pdfcrypt.js`): pdf-lib шифровать не умеет. Проверено двумя независимыми читалками — pdf.js и poppler.
- **PDF → Word**: текст собирается в абзацы, крупный шрифт становится заголовками, картинки встают на свои места, одна страница PDF — одна страница Word.
- **«Картинки» из PDF**: JPEG достаются как есть, байт в байт; остальное — в PNG (с прозрачностью, если она была).
- **«Сжать PDF»** пережимает крупные картинки (до 1600 px по длинной стороне) и сжимает служебные потоки; если выигрыша нет, честно говорит «уже сжат».
- **BMP, TIFF (LZW), GIF (256 цветов с рассеиванием ошибки) и ICO** canvas сохранять не умеет — кодировщики написаны свои (`lib/encoders.js`) и проверены сторонней библиотекой (Pillow).
- Файлы пишутся атомарно: сначала скрытый `.~имя.part`, потом переименование — в Проводнике никогда не мелькнёт недописанный файл.
- Тип файла определяется ещё во время перетаскивания (по MIME), поэтому меню сразу показывает нужные действия. Если тип не угадан — брось файл в центр меню, и оно откроется для выбора щелчком.
- Тяжёлая работа (картинки, страницы PDF) идёт в отдельном невидимом окне со своим процессом: оболочка не подвисает. Окно поднимается при первом использовании и закрывается после 2 минут простоя.
- Настройки — «Настройки → Конвертер»: клавиша (Shift/Ctrl/Alt), куда сохранять, качество, лимит для «≤ размер», разрешение PDF → картинки, пункт в «Отправить».

**Жест — как в оригинале.** `bridge.ps1` каждые 15 мс смотрит на левую кнопку мыши, клавишу и Esc (без хуков — опрос не может подвесить ввод системы). «Кнопка зажата + мышь сдвинулась на 10 px + клавиша нажата» — так выглядит Shift+перетаскивание файла из любой программы. Меню прячется, когда кнопку отпустили (через 120 мс, чтобы бросок успел долететь) или нажали Esc, и само уходит с дороги, если курсор двигается, а файл до меню так и не долетел (это было перетаскивание окна или выделение текста с Shift). В игре на весь экран меню не появляется. На Linux и в демо-режиме — через «Преобразовать…».

Чего нет по сравнению с оригиналом: выходные форматы HEIC и AVIF и чтение HEIC/TIFF — в Chromium нет таких кодеков.

Библиотеки: [pdf-lib](https://github.com/Hopding/pdf-lib) (MIT), [pdf.js](https://github.com/mozilla/pdf.js) (Apache-2.0), [mammoth](https://github.com/mwilliamson/mammoth.js) (BSD-2), [docx](https://github.com/dolanmiu/docx) (MIT).

## Производительность

Что сделано, чтобы оболочка не грела процессор и не съедала память:

- **Два процесса на всё встроенное.** Обычно каждое окно Electron — отдельный процесс (~30 МБ). Здесь невидимые окна-«хозяева» открывают остальные через `window.open`, и Chromium селит их в свой процесс: все встроенные виджеты — в одном, панель, остров, док и поиск — во втором (`lib/hosts.js`). Свои виджеты — в отдельных процессах: это чужой код, и если он зависнет, остальное продолжит работать.
- **Умная пауза** (`power.js`). Игра или фильм на весь экран, заблокированный экран, сон — анимации стоят, звук не анализируется. Работа от батареи или 3 минуты без мыши и клавиатуры — вдвое меньше кадров.
- **Кадры только когда нужны.** У каждого виджета своя частота, и она подстраивается на ходу: визуализатору 24 кадра со звуком и 6 в тишине (на Windows — по реальной громкости, а не «звук захвачен»), глазкам 20 при движении мыши и 8 в покое, часам 4, кассете 4 на паузе, погоде 2. Часы и глазки перерисовываются, только если картинка правда изменилась; новые виджеты (расписание, заметки, отсчёт) вообще без анимации — обновляются по событию. Между кадрами окно ждёт таймером, а не `requestAnimationFrame` — иначе Chromium гонял бы полный цикл кадра 60 раз в секунду, даже когда рисовать нечего.
- **Точки пачками.** Сотни точек рисуются одним `fill()` на цвет, а не по одной.
- **Никаких бесконечных CSS-анимаций.** Бегущие строки и эквалайзеры двигает само окно на своих кадрах (`Dot.marquee`, `Dot.eq`): бесконечная CSS-анимация заставляла бы окно перерисовываться 60 раз в секунду, даже если виджет рисует 6. Остров сдвигает строку целыми точками 12 раз в секунду.
- **Ничего лишнего в DOM.** Цвета темы и размеры canvas запоминаются, текст пишется, только если поменялся; погасшие точки визуализатора рисуются один раз в буфер, яркость точек — шесть ступенек, чтобы рисовать их несколькими заливками.
- **Меньше пересылок.** Обложка трека (сотни КБ) уходит окнам только при смене трека, состояние плеера — только при паузе, перемотке или новом треке. Мост к Windows собирает список окон на C# (с кэшем путей к программам) и присылает его, только когда он изменился; музыку опрашивает раз в секунду во время игры и раз в 2 секунды в тишине. Глазки спрашивают положение курсора 20 раз в секунду, только пока мышь двигается. Звук для визуализатора захватывается без видео экрана.
- **Диск и сеть.** Настройки пишутся на диск не чаще раза в 300 мс, список файлов для поиска живёт 30 секунд, иконки кэшируются.
- **Память.** Библиотеки конвертера (pdf-lib и др.) грузятся при первом использовании; проверка орфографии, перехват медиаклавиш Chromium и его «запасной» процесс выключены, молодое поколение кучи V8 меньше.
- **Эко-режим** — вдвое меньше кадров всегда, даже от сети.
- **Скрытые окна не рисуются.** Окно, закрытое другими, свёрнутое или спрятанное Alt+W, кадров не тратит.
- Сразу включены только основные виджеты: часы, погода, календарь, визуализатор, глазки, ярлыки, расписание. Остальные — в «Настройки → Виджеты».
- Учитывается параметр Windows «Эффекты анимации: выкл.».

Замер в демо-режиме (Linux без видеокарты: всё рисует процессор, поэтому проценты сильно завышены, но для сравнения годятся):

| | Было | Стало |
|---|---|---|
| Все 12 виджетов, играет музыка | 183% ядра, 617 МБ, 23 процесса | 104% ядра, 462 МБ, 9 процессов |
| Виджеты по умолчанию, играет музыка | 72% ядра, 388 МБ (раньше) → 54,6%, 392 МБ | 29% ядра, 368 МБ, 8 процессов |
| Виджеты по умолчанию, тишина | 38% ядра → 29,2% | 11,3% ядра, 361 МБ |
| То же + расписание (7 виджетов), музыка, эко-режим | — | 22% ядра |
| Игра на весь экран, экран заблокирован | — | ~2% ядра |

## Свои виджеты

1. ПКМ по доку → Виджеты → «Папка своих виджетов…» (это `%APPDATA%\familiar-lite\widgets\`).
2. Положи туда `мой-виджет.js`. Внутри вызови `Widget.define('мой-виджет', (card) => { ... })`, имя должно совпадать с именем файла.
3. ПКМ → Виджеты → «Обновить свои виджеты».

Все доступные функции описаны в комментарии в начале `examples/pomodoro.js`. Свой виджет получает тот же доступ, что и встроенные (может запускать программы), поэтому не клади туда файлы из непроверенных источников.

## Настройки

Всё настраивается в окне «Настройки» (FAMILIAR в панели → «Настройки…» или ПКМ по доку). Хранится локально в `%APPDATA%\familiar-lite\config.json`: профили с фото, закреплённые приложения, погода, тема, палитра, обои, напоминания, положение виджетов. Облачной синхронизации нет — как и в бете оригинала.

## Устройство

- `main.js` — главный процесс: окна, меню, док, профили, обои.
- `lib/bridge.js` + `bridge.ps1` — связь с Windows; в демо-режиме выдуманные данные.
- `lib/apps.js`, `lib/games.js`, `lib/system.js` — поиск приложений, игры, нагрузка и батареи.
- `lib/files.js`, `lib/profiles.js` — папка Familiar и ярлыки, профили.
- `lib/hosts.js` + `src/host.html` — окна-«хозяева»: несколько окон в одном процессе.
- `lib/convert.js`, `lib/imagemeta.js` — конвертер: действия, PDF/Word/текст, метаданные картинок.
- `lib/encoders.js` (BMP, TIFF, GIF, ICO, PNG), `lib/pdfcrypt.js` (пароль AES-256), `lib/pdfimages.js` (картинки внутри PDF: достать и пережать).
- `src/converter.*` — рабочее окно конвертера (canvas и pdf.js), `src/radial.*` — круговое меню, `src/toast.*` — уведомление, `src/tool.*` — окна инструментов (обрезка, правка, пометки…).
- `lib/palette.js` — палитры и подбор цветов по обоям; `preload.js` вставляет их в каждое окно поверх `src/theme.css`.
- `src/power.js` — режим питания в окнах (пауза в играх, экономия на батарее).
- `preload.js` — какие функции главного процесса доступны окнам.
- `src/dotmatrix.js` — точечный шрифт 5×7 (латиница, кириллица, цифры).
- `src/media.js`, `src/audio.js` — состояние плеера и спектр звука для окон.
- `src/menubar.*`, `src/island.*`, `src/dock.*`, `src/launcher.*`, `src/wallpaper.*` — панель, остров, док, поиск, обои.
- `src/settings.*`, `src/files.*` — окна «Настройки» и «Файлы».
- `src/quick.js` — быстрые ответы поиска: калькулятор (свой разбор выражений, без `eval`), единицы, команды.
- `src/widget.html` + `src/widgets/*.js` — по файлу на виджет.
- `examples/pomodoro.js` — пример своего виджета, при первом запуске копируется в папку виджетов.
